# IT Lab Social Media Strategy
Version 1.0 | 2026-10-23 | Status: Strategy; no accounts or posts created

## Objectives and platforms
LinkedIn (primary) for a credible professional profile, IT contacts, partnerships, technical case studies and knowledge exchange. X (primary) for compact tips, progress notes and international discussion. Facebook for Georgian community reach when needed; YouTube for demonstrated procedures requiring visual walkthrough; Instagram for suitable visuals. Do not open everything at once.

## Audience and positioning
Primary: IT practitioners, system/network administrators, programmers and technical educators. Secondary: institutions and teachers seeking practical educational technology. Position IT Lab as evidence-driven, reproducible and community-oriented, not a generic advertising page.

## Content streams
Verified troubleshooting lesson with canonical handout link; short technical tip with one testable outcome; implementation demo showing limits; open question for peer review; educational tool development update; relevant community invitation; technical event recap. Do not disclose confidential cases. Explain use value, not unsupported claims.

## Content workflow
Technical owner submits evidence → privacy and correctness review → choose audience/platform → adapt to short Georgian post (or English/bilingual when audience justifies) → obtain publication authorization → publish → answer genuine questions → log metrics and update canonical knowledge for reusable feedback.

## Identity, moderation and measurement
Use consistent IT Lab name and imagery, accurate profile description, official GitHub destination, accessible text alternatives and respectful response style. Track qualified visits to canonical resources, relevant conversations, useful contributions, voluntary community joins and content production effort; treat vanity reach metrics as secondary. Review monthly or after an actual campaign.
