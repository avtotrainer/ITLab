# Messaging Platforms
Version 1.0 | 2026-10-23 | Default administration language: Georgian

## Selection matrix
Telegram: broadcast channel or technical group where large, asynchronous public/semipublic participation is useful; review message visibility and bots. WhatsApp/Business: smaller phone-linked outreach or direct service communication; consider phone-number exposure and consent. Signal: privacy-sensitive small group communication where supported features fit. Facebook Messenger: lightweight contact for a Facebook-based audience. Discord: multi-topic online community only when Slack cannot serve the audience. Microsoft Teams: organizational collaboration in an existing Microsoft ecosystem. Select only a demonstrably useful platform.

## Architecture
GitHub and Drive remain the knowledge source. Slack is preferred for IT Lab structured professional discussion if the correct workspace is connected. Secondary messengers serve notifications, events or an audience that cannot reasonably use Slack. Never fragment full support answers across unindexed private chats. No automatic mass invites or imported contacts.
