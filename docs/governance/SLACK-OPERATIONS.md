# Slack Operations — IT Lab
Version 1.0 | 2026-10-23 | State: Proposed for dedicated IT Lab workspace

## Verified connector discovery
The connected Slack account exposed #slack-learning, #social, #introductions, #all-teacher-collaboration-lab and #practical-tasks. These refer to Teacher Collaboration Lab context, not a verified dedicated IT Lab community. DO NOT create IT Lab channels there without explicit workspace confirmation. The workspace inventory and administrative permissions for a dedicated IT Lab Slack have not been verified.

## Proposed minimal channel map
#announcements — official updates (moderated posting); #general — cross-topic discussion; #introductions — new members; #helpdesk — structured technical support; #windows — Windows/Microsoft; #linux-nixos — Linux/NixOS; #networking — connectivity/infrastructure; #development — programming/automation; #edtech — school technology; #resources — reusable public references; #projects — active collaboration. Only create channels justified by actual need; combine underused topics first.

## Naming and moderation
Use lowercase hyphenated topic names. Public channels for common topics, private only for justified restricted discussions. Channel topic and description must link to purpose, posting norms, moderator and canonical references. Require consent before inviting users or adding integrations. Do not post passwords, student information, private addresses or raw organizational logs. Pin an onboarding message with conduct, channel map, help request format and knowledge links. Use threads for one problem and post a final evidence-backed resolution.
