# Repository Structure
Version 1.0 | 2026-10-23

## Observed baseline
The repository started with docs/nixos/HP-LASERJET-M102W-WIFI-CUPS-HANDOUT.md. This historical path is stable and is not a migration target.

## Actual root and responsibilities
- README.md: discoverability and navigation.
- docs/governance/: constitution, instructions, documentation, security, community, campaigns and process standards.
- docs/knowledge/: knowledge register and searchable cross-references.
- docs/nixos/: existing NixOS device/printer technical handouts.

## Extensible conventions (create only with content)
docs/handouts/ka/ for general Georgian handouts; docs/windows/, docs/microsoft/, docs/networking/, docs/hardware/, docs/development/, docs/education/ for topical notes; docs/community/, docs/social-media/, docs/messaging/ for published content; docs/runbooks/ for verified operations; configs/, scripts/, projects/ for real implementations.

Directory choice follows topic and ownership. A handout must not move simply to match an ideal tree. Changes that rename canonical paths require rationale, explicit authorization when material, redirect/link repair and a verified register update.
